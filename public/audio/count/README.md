# Count samples

Recorded spoken count for Count mode (ADR-0008). Mono WAV, 44.1 or 48 kHz, 16-bit, trimmed so the onset starts at sample 0, each under 250 ms so they fit between eighth notes at 120 BPM.

Required files:

- `one.wav`, `two.wav`, `three.wav`, `four.wav`
- `and.wav`

For meters with more beats: `five.wav` … `nine.wav`.

Until recordings exist, the app falls back to short synthesised tones (beat 1 high, other beats middle, "and" low), as in the design prototype.
